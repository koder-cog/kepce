## Permitted Uses

You may use the Kepçe name and logo without prior written consent in the following cases:

- Factual attribution: Describing your application or service as built with, powered by, or forked from Kepçe (e.g., "Powered by Kepçe API", "Based on the Kepçe open-source project").
- Project links: Linking directly to https://kepce.org or the official GitHub repository.
- Editorial and community use: Referencing Kepçe in articles, academic work, tutorials, or public discussions.

## Prohibited Uses

Unless you have explicit written permission from the maintainers, you may not:

- Imply endorsement or affiliation: Present a fork, self-hosted deployment, or derivative service as the official Kepçe instance or as certified/endorsed by the project.
- Use Kepçe as a primary brand: Name an independent fork, product, or service "Kepçe" or use a confusingly similar name.
- Register confusing domains or handles: Register domain names, application packages, or social media accounts that include "kepce" in a way that risks misleading users.
- Commercial branding: Sell merchandise or commercial services branded with the Kepçe logo without consent.

## Rules for Forks and Hosted Instances

If you fork the repository or run a public server instance:

1. Rebrand the deployment: Remove the official Kepçe logo and visual assets. Choose a distinct name so users understand they are accessing an independent service.
2. Keep copyright and license notices: Retain all AGPLv3 notices and provide access to your modified source code as required by AGPLv3 Section 13.
3. Attribution: You are welcome to state in your footer or documentation that your deployment is based on the Kepçe open-source project.
